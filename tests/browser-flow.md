# 候场浏览器流程验证

验证日期：2026-08-14
环境：本地开发站点，独立参赛端与主持端页面

- 参赛者通过活动链接、房间码、昵称和 Agent 名称成功加入。
- 刷新参赛页面后，同一浏览器通过本地恢复凭据回到原席位。
- 三名参赛者加入后，主持端显示席位、昵称、Agent 名称与连接状态。
- 主持人启动第一版后名单锁定；迟到加入返回 `roster-locked`，未增加席位。
- 主持人在匿名阅卷前移除故障席位后，原参赛者可以重新加入，席位总数仍受锁定上限约束。

补充自动化覆盖：`tests/lobby.test.ts` 固定了锁定、拒绝迟到加入、释放席位后重新加入以及界面加入可用性；`tests/d1-activity-store.test.ts` 固定了 D1 持久化、能力链接隔离和旧活动房间码迁移。
