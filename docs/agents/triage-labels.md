# Triage 标签

| 统一角色 | 本工程状态值 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待负责人评估 |
| `needs-info` | `needs-info` | 等待补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可交给 Agent 执行 |
| `ready-for-human` | `ready-for-human` | 需要人工处理或确认 |
| `wontfix` | `wontfix` | 决定不处理 |

技能提及 triage 角色时，使用本表对应的状态值。
