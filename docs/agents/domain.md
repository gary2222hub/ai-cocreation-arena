# 领域文档

工程技能在分析或修改项目之前，按以下规则读取领域资料。

## 读取入口

- 根目录的 `CONTEXT.md`
- `docs/adr/` 中与当前工作相关的 ADR

如果文件尚不存在，直接继续，不要预先创建。只有在术语或决策真正达成共识后，才通过领域建模流程创建或更新。

## 文档结构

本工程采用单一上下文：

```text
/
├── CONTEXT.md
├── docs/
│   └── adr/
└── src/
```

## 统一语言

涉及领域概念时，使用 `CONTEXT.md` 已定义的术语。不要随意替换为近义词；遇到未定义概念时，将其作为待确认的领域问题。

## ADR 冲突

如果拟议工作与现有 ADR 冲突，必须明确指出，不得静默覆盖已有决策。
