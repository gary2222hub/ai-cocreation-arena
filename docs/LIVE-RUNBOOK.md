# 两轮现场运行清单

## 创建活动

每个创建邀请码均只能使用一次。请由部署者通过私密方式创建和分发邀请码，不要写入公开仓库或活动材料。

1. 打开网站首页，选择默认的“两轮简化流程”。
2. 填写活动名称、开始结束时间、人数和两轮正式题目。
3. 创建后立即保存主持人、参赛者和大屏三个链接，以及房间码。
4. 将参赛者链接和房间码发给参会者；主持人链接只由主持人保留。

## 现场顺序

1. 参赛者加入候场，主持人确认至少 3 人。
2. 主持人点击“播放自然语音开场”；页面会优先选择设备中较自然的中文声线。如听感仍不合适，点击“复制开场词”后由主持人介绍。
3. 主持人点击“启动第一版并锁定名单”。
4. 参赛者完成并保存 V1；主持人口头倒计时后点击“结束 V1，进入 V2”。
5. 参赛者填写唯一追加 Prompt 和 V2；主持人结束 V2。
6. 每人匿名选择一个最喜欢的作品，不能自投；主持人结束投票。
7. 主持人揭晓身份，再开始自由交流。
8. 自由交流不会自动结束；主持人确认讨论完成后手动结束。
9. 默认按互评票数直接公布结果。若希望补充评分，主持人可复制或下载全部匿名作品，发送给自己选择的 AI 工具，再将返回的 0–10 整数评分填回页面；公共版本不会调用任何默认模型账户。
10. 主持人公布本轮结果。第一轮后点击启动第二轮，第二轮后完成活动。
11. 最终页面公布两轮累计成绩；同分直接并列。前三名获得冠亚季军，其余参赛者依次获得“最幽默表达奖、最犀利批判奖、最像老板奖、最佳战略奖”。
12. 活动结束后打开报告入口，下载“整场 JSON”保存完整题目、作品、投票、AI评分和总成绩。

## 现场规则

- 以主持人口令和外部计时器为准，网页不自动倒计时。
- 点击阶段结束后，上一阶段内容立即锁定且不能回退。
- 默认单轮成绩 = 互评票数；填写可选外部评分后，单轮成绩 = 外部评分（0–10）+ 互评票数；两轮直接相加。
- V1 与 V2 各允许最多 700 字，追加 Prompt 最多 500 字。
- 匿名互评前如有参赛者浏览器故障，主持人可移除席位后让其重新加入。
- 匿名互评开始后不再更换席位。
