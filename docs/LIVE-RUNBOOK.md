# 两轮现场运行清单

> 公开仓库版本不包含真实邀请码、活动链接、房间码、访问令牌或默认模型密钥。请通过私密部署渠道配置活动。

## 创建活动

1. 打开网站首页，选择默认的“两轮简化流程”。
2. 填写活动名称、开始结束时间、人数和两轮正式题目。
3. 创建后立即保存主持人、参赛者和大屏三个链接，以及房间码。
4. 将参赛者链接和房间码发给参会者；主持人链接只由主持人保留。

## 现场顺序

1. 参赛者加入候场，主持人确认至少 3 人。
2. 主持人播放浏览器内置语音开场；若听感不合适，复制开场词人工介绍。
3. 主持人启动第一版并锁定名单。
4. 参赛者完成并保存 V1；主持人口头倒计时后结束 V1，进入 V2。
5. 参赛者填写追加 Prompt 和 V2；主持人结束 V2。
6. 每人匿名选择一个最喜欢的作品，不能自投；主持人结束投票。
7. 主持人揭晓身份，再开始自由交流。
8. 自由交流由主持人手动结束。
9. 默认按互评票数直接公布结果。若希望补充评分，主持人可复制或下载全部匿名作品，发送给自己选择的 AI 工具，再将返回的 0–10 整数评分填回页面；公共版本不会调用任何默认模型账户。
10. 公布本轮结果；第一轮后启动第二轮，第二轮后完成活动。
11. 最终页面公布两轮累计成绩；前三名及文字表达类特色奖项。
12. 活动结束后下载整场 JSON 报告保存。

## 现场规则

- 以主持人口令和外部计时器为准，网页不自动倒计时。
- 点击阶段结束后，上一阶段内容立即锁定且不能回退。
- 默认单轮成绩 = 互评票数；填写可选外部评分后，单轮成绩 = 外部评分（0–10）+ 互评票数；两轮直接相加。
- 匿名互评前如有浏览器故障，主持人可移除席位后让其重新加入。
